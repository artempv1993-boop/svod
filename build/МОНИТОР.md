# Монитор прохождения опросов (формат Adelina)

`../index.html` — свод «кто прошёл опросы» в вёрстке коллеги Adelina
(`adelinaatp-source.github.io/opros/`), на данных **survey-bot**.

## Что показывает
Полный ростер оргструктуры × прохождение 3 сценариев (Процесс / Доопрос / Фото дня):
кто прошёл (✓ ×N), кто ещё нет (красным), разрез по управлениям, KPI и охват.
`noindex` — страница закрыта от поисковиков (в ней ФИО).

## Учёт (как у Adelina)
- Сессии считаются **сыром**: все, включая тест-аккаунты и пустые (`RAW_MODE=True`).
- Дубли ростера (точки-аккаунты) — схлопывает JS-логика шаблона (показ 390 из 486).
- Переключить на «по новому» (только валидные ≥1 закрытие, без теста) — `RAW_MODE=False` в `gen_monitor.py`.

## Пересборка (из этой папки `build/`)
```
python gen_monitor.py     # survey-bot/storage/output + справочник current.json → raw.json
python build_adelina.py   # raw.json → шаблон adelina.html → index.html
```
Затем скопировать полученный `build/index.html` в корень репозитория (`../index.html`) и запушить.

## Файлы
- `gen_monitor.py` — строит `RAW` из вывода survey-bot и справочника оргструктуры.
- `build_adelina.py` — подставляет `RAW` в шаблон.
- `adelina.html` — шаблон-референс (страница Adelina). Не редактировать вручную.
