Бот не спрашивает фамилию и номер ОП: часть товароведов назвалась только именем, а аккаунты @CKCLombard_70 и @skslombardnagaevo общие на точку. Такие анкеты отнесены в «Товароведы» как «ФИО не определено». Сверка оставшихся имён с точками (ОП) — следующий шаг.

Замечания

«Коммерческое управление» — больше половины базы ( из с учётом бота). Ядро бизнеса — займы, скупка, розница, автозайм — описано плотнее всего; лидируют Супервайзеры, КМ Золото и товароведы (через бота).

Автор не установлен у документов: указана только должность, а приславший заведомо не владелец процесса. Именной зачёт не проставлен намеренно — иначе свод покажет сдачу за тех, кто процесс не описывал. Отдел подставлен по отправителю; у не определён и отдел.

Линейное звено — через бота. Товароведы (194 чел. по штатке) сдают преимущественно через Telegram-бот; их анкеты сведены в отдел «Товароведы» Коммерческого управления. Часть опознана по ФИО, часть — как «ФИО не определено» (см. блок «Telegram-бот — как учтён»).

Источник: уложенные документы Слоя 1А из базы знаний (только чтение) + оргструктура Битрикс24 + журнал Telegram-бота. Отнесение — по автору (frontmatter owner), опознанному по штатке; при неопознанном авторе — по отправителю в чате, отправитель автором не становится. Управление — родительское подразделение отдела по оргструктуре. Внутренний документ ООО «СКС Ломбард».
Сценарии: S1 Процессы (описание процесса) · S2 Пробелы (доопрос) · S3 Фото рабочего дня

Охват по управлениям прошли ≥1 сценария из штата · разверните управление, чтобы увидеть сотрудников

Опрос стартовал. survey-bot собирает три сценария — Процессы, Пробелы, Фото рабочего дня. В отличие от прежнего бота, он сам определяет ФИО, отдел и управление по Битрикс24, поэтому ручная сверка имён не нужна, а охват считается сразу от штата.

«Не прошли» показаны счётчиком по управлениям — без пофамильного списка (ссылка публичная, хоть и noindex). Поимённо видно только тех, кто уже прошёл.

Источник: survey-bot — журнал завершённых сессий + оргструктура Битрикс24. Охват = доля активных сотрудников, прошедших ≥1 сценария. Персональные данные (телефоны) в свод не выгружаются. Внутренний документ ООО «СКС Ломбард».
