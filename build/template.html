Бот не спрашивает фамилию и номер ОП: часть товароведов назвалась только именем, а аккаунты @CKCLombard_70 и @skslombardnagaevo общие на точку. Такие анкеты отнесены в «Товароведы» как «ФИО не определено». Сверка оставшихся имён с точками (ОП) — следующий шаг.

Замечания

«Коммерческое управление» — больше половины базы ( из с учётом бота). Ядро бизнеса — займы, скупка, розница, автозайм — описано плотнее всего; лидируют Супервайзеры, КМ Золото и товароведы (через бота).

Автор не установлен у документов: указана только должность, а приславший заведомо не владелец процесса. Именной зачёт не проставлен намеренно — иначе свод покажет сдачу за тех, кто процесс не описывал. Отдел подставлен по отправителю; у не определён и отдел.

Линейное звено — через бота. Товароведы (194 чел. по штатке) сдают преимущественно через Telegram-бот; их анкеты сведены в отдел «Товароведы» Коммерческого управления. Часть опознана по ФИО, часть — как «ФИО не определено» (см. блок «Telegram-бот — как учтён»).

Источник: уложенные документы Слоя 1А из базы знаний (только чтение) + оргструктура Битрикс24 + журнал Telegram-бота. Отнесение — по автору (frontmatter owner), опознанному по штатке; при неопознанном авторе — по отправителю в чате, отправитель автором не становится. Управление — родительское подразделение отдела по оргструктуре. Внутренний документ ООО «СКС Ломбард».
Собрано по фактически выложенным файлам бота. Каждый файл проверен: содержательный — заполнен по стандарту · частичный — сессия оборвана / мало ответов · пустой — файл без содержания (в зачёт не идёт).

Вторая итерация — новый бот survey-bot (три сценария: Основной опрос — описание процесса, Доопрос — закрытие пробелов, Фото рабочего дня). Бот сам определяет ФИО, отдел и управление по Битрикс24. Идёт тест-фаза — много частичных/оборванных сессий, они показаны отдельно от содержательных.

Считаем по каждому файлу результата (повторные сессии одного человека — каждая отдельно). Поимённо видно только тех, у кого есть непустой файл; пустые/оборванные — счётчиком.

Источник: survey-bot/storage/output/<сценарий> — фактические файлы результатов + оргструктура Битрикс24. Автор/отдел/управление — по bitrix_id из frontmatter. ПДн (телефоны) не выгружаются. Внутренний документ ООО «СКС Ломбард».

По направлениям первая итерация (Слой 1А) — основной корпус документов

Итерации и сценарии общая картина сбора

Общая картина. Первая итерация — уложенный корпус Слоя 1А (документы по процессам, чат + Telegram-бот), разложен по направлениям выше. Вторая итерация — новый бот survey-bot, пока тест-фаза (сессии по трём сценариям).

Итерации меряют разное: первая — готовые документы процессов, вторая — сессии опроса сотрудников. Поэтому сведены рядом, а не в одну сумму.

Первая итерация — база знаний Слоя 1А (NAS) + оргструктура Битрикс24. Вторая — файлы результатов survey-bot. Снимок на дату. Внутренний документ ООО «СКС Ломбард».
