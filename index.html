Часть аккаунтов бота принадлежит точке, а не человеку
С @CKCLombard_70 и @skslombardnagaevo анкеты сдают разные товароведы одной точки — аккаунт общий на подразделение. Опознать автора по нему нельзя, только уточнением у супервайзера точки. Поэтому имена из бота со штаткой не сверяются и к отделам не относятся.

Замечания

«Коммерческое управление» — больше половины базы ( из по чату). Ядро бизнеса — займы, скупка, розница, автозайм — описано плотнее всего; внутри лидируют Супервайзеры и КМ Золото.

Автор не установлен у документов: указана только должность, а приславший заведомо не владелец процесса. Именной зачёт не проставлен намеренно — иначе свод покажет сдачу за тех, кто процесс не описывал. Отдел подставлен по отправителю; у не определён и отдел.

Щербакова Т. В. выбыла из компании — её отдел считаем как раньше
Щербакова Татьяна Викторовна (руководитель ОУиМ, 5 документов) больше не числится в активной оргструктуре Битрикс24. Автосвод по совпадению «фамилия + имя» приписывает её документы Щербаковой Татьяне Евгеньевне (проектное управление), игнорируя отчество. В этом снимке 5 документов вручную возвращены в Операционное управление — счёт по её отделу сохранён.

Линейное звено видно только через бота. Товароведы (194 чел.) и обособленные подразделения сдают преимущественно через бота, поэтому их вклад — в блоке Telegram, а не в отделах Коммерческого управления.

Источник: уложенные документы Слоя 1А из базы знаний (только чтение) + оргструктура Битрикс24 + журнал Telegram-бота. Отнесение — по автору (frontmatter owner), опознанному по штатке; при неопознанном авторе — по отправителю в чате, отправитель автором не становится. Управление — родительское подразделение отдела по оргструктуре. Внутренний документ ООО «СКС Ломбард».
