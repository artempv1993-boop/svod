# Своды по опросу процессов — публичные страницы

Два обезличенных свода на GitHub Pages:

- **[Свод по опросу владельцев процессов](https://artempv1993-boop.github.io/svod/)** (`index.html`) —
  первая волна: чат Битрикс24 «Интервью по процессам» и Telegram-бот для товароведов.
- **[Внедрение ИИ: результаты автоматизации](https://artempv1993-boop.github.io/svod/ii.html)** (`ii.html`) —
  итоги задачи Битрикс24 «Автоматизация описанных бизнес-процессов».

## Персональных данных здесь нет

Страницы публичные (доступны по ссылке), поэтому содержат **только агрегаты**: итоги, проценты
и разрезы по управлениям и по подразделениям, где работает **5 и более человек**. Подразделения
меньшего размера объединены в «Прочие подразделения».

**Что сюда не попадает никогда:** ФИО, должности, строки по отдельным сотрудникам, отметки
времени активности, промежуточные файлы сборки (`payload.json`, `roster.json`, `report.md`,
`adelina.html`).

Детальные своды «кто сколько прошёл» с фамилиями ведутся в приватной базе знаний
(`knowledge-base/01_Справочная-информация/Своды опросов — детальные отчёты (ПДн)/`) и
предоставляются руководству отдельным документом.

## Как обновить

Страницы **не редактируются руками** — они собираются скриптом из приватных исходников:

```
python knowledge-base/_scripts/svod-anon-build.py
```

Скрипт пересобирает `index.html` и `ii.html`, после чего сам проверяет результат на
персональные данные (ФИО, должности, телефоны, почты) и **прерывает работу, если что-то
просочилось**. Затем — обычный `git add` → `git commit` → `git push`.

`.gitignore` устроен по принципу «запрещено всё, разрешено поимённо»: новый файл не попадёт
в публикацию, пока его не разрешат явной строкой.

> Внутренний ресурс ООО «СКС Ломбард». Ссылка публичная, из поисковой выдачи скрыта (`noindex`).
